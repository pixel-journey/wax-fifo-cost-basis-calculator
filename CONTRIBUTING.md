# Contributing

Open a PR against `main`. `npm test` and `npm run typecheck` must pass.

- Keep `examples/fifo.ts` free of `fetch`, wallets, and React.
- Add a test for every new matching rule.
- Do not raise the trust label in the README without a new row in `VERIFICATION-LOG.md`.
- Do not present fictional or sample asset ids as live market facts.

MIT. Educational reference for WAX and Antelope developers.
